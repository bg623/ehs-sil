生态环境法典8月15日施行：10部环保法律废止后EHS文件怎么改

不需要把所有EHS体系文件推倒重写，也不能只在法规清单中删除10部旧法。正确动作是：改引用、做映射、查变化、补缺口，并保留完整的换版证据。

实施提醒：《中华人民共和国生态环境法典》于2026年3月12日通过，自2026年8月15日起施行。法典第一千二百四十二条明确列出同时废止的10部法律。

哪10部环保法律同时废止？

序号2026年8月15日起废止主要管理主题
1环境保护法综合环境管理与法律责任
2环境影响评价法规划和建设项目环评
3海洋环境保护法海洋污染防治
4大气污染防治法废气和大气污染防治

10清洁生产促进法清洁生产与绿色低碳发展

旧法废止不等于义务消失。原有主要制度被系统编纂进法典，同时条款编号、结构和部分要求发生变化；其他生态环境相关法律也并非全部废止。

为什么不能“一键替换”法律名称？

条款编号和适用逻辑已经重构

原文件引用的“某法第×条”需要找到法典对应条款，并确认义务是平移、合并、修改，还是新增了适用条件。仅替换法律名称而保留旧条款号，会形成错误引用。

核心环境义务仍需持续运行

排污许可、自行监测、污染防治设施、危险废物、突发生态环境事件、环评和信息披露等管理不能因为旧法废止而中断。

配套规定仍在持续清理

生态环境部已经对30余部行政法规、80余件部门规章和400余件规范性文件开展梳理评估。企业还需继续关注国家和地方后续发布的正式废止、修改及衔接文件。

EHS文件分三类处理

第一类：必须立即换版

  • 适用法律法规及其他要求清单；
  • 合规义务识别与评价控制程序；
  • 年度合规性评价报告；
  • 环境法律法规培训材料；
  • 内审、专项检查和管理评审法规检查表；
  • 明确引用10部旧法及具体条款的制度、预案和作业文件。
保留追溯：旧法状态标记为“2026年8月15日废止”，新增法典并标记施行日期；保留旧法在历史期间的适用记录，不能直接删除。

第二类：优先复核，不一定全部重写

模块重点复核
环境责任制单位负责人、部门和岗位责任
建设项目与变更环评、环保“三同时”、重大变动触发
排污许可与监测许可事项、执行报告、点位指标频次、记录保存
污染与废物管理废气、废水、噪声、固废、危废全过程管理
土壤地下水与应急隐患排查、监测、物资、演练、报告与备案
信息披露与低碳企业身份、披露义务、能源和碳管理适用性

第三类：不会因换版自动失效

仍在有效期内的许可证、已批复的环评和验收资料、历史监测与危废记录、有效服务合同，以及未引用旧法且要求未变化的现场规程，不会仅因法律换版自动失效。企业仍需结合实际变化和主管部门要求判断。

施行日前优先完成的5个动作

  1. 更新法规总清单：新增法典，标记10部旧法废止，不删除历史记录；
  2. 建立映射表：至少包含旧法、旧条款、法典条款、义务变化、涉及部门、关联文件、措施、责任人、期限和证据；
  3. 优先查高风险义务：排污许可、监测、危废、应急、建设项目变更、土壤地下水和信息披露；
  4. 形成受控修订计划：区分立即修订、评估后修订和确认无实质变化；
  5. 持续跟踪配套文件：关注国家及地方正式清理结果和执法衔接要求。

最容易踩的4个坑

  1. 只删旧法，不记录替代关系；
  2. 批量替换法律名称，却保留原条款号；
  3. 只更新法规清单，不复核业务文件；
  4. 8月15日更新一次，此后不再跟踪配套文件。

常见问题

10部环保法律废止后，EHS体系文件需要全部重写吗？

不需要。应按文件风险和引用情况分类处理，直接引用旧法的文件立即换版，高风险业务模块优先复核，要求未变化的文件无需为了留下修订痕迹而整篇重写。

法规清单中的10部旧法可以直接删除吗？

不建议。应保留历史记录并标记废止日期，同时新增法典、记录替代关系和新旧条款映射，保证历史合规评价与审核证据可追溯。

排污许可证会自动失效吗？

不会仅因法律换版自动失效。企业应结合许可证有效期、项目与排污事项变化、法典规定以及主管部门最新要求逐项判断。
