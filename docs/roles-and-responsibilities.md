# 职责与责任边界

版本：1.0  
生效日期：2026-07-29

## Codex 负责

- 文档模板；
- 数据结构；
- 前端与后端开发；
- 数据埋点；
- 规则引擎；
- 自动化测试；
- 数据汇总；
- 发布记录；
- 记录已知限制和待确认事项。

Codex 必须：

- 将事实、假设、模拟数据和真实数据明确区分；
- 对未经产品负责人审核的专业规则标记为不可上线；
- 在规则或逻辑变化后运行回归测试；
- 在发布前报告测试范围、结果和剩余风险。

## 产品负责人负责

- 用户招募；
- 用户访谈；
- 提供脱敏 JSA 样本；
- 审核专业规则；
- 确认用户反馈；
- 决定价格和权益；
- 批准最终上线；
- 确认实验结论是否代表真实业务判断。

## 禁止事项

Codex 不得：

- 虚构用户访谈；
- 虚构 JSA 样本；
- 虚构用户反馈、付费意愿或测试结果；
- 将演示数据计入实验指标；
- 未经审核将专业规则标记为已批准；
- 代替产品负责人作出最终上线批准。

## 发布批准

任何生产部署必须同时满足：

1. 自动化测试通过；
2. 专业规则已由产品负责人审核；
3. 已知限制已记录；
4. 产品负责人明确批准上线。
