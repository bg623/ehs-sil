## 4. 已复现并修复的问题

1. **JSA专业用词混用**：L×S被称为RPN。已统一为“风险分值（L×S）”与对应等级；企业仍须复核默认矩阵。未改变1–4/5–9/10–16/17–25阈值，未改FMEA。
2. **反馈假成功**：基线中空JSON的200响应被接受。现要求 `ok=true` 和符合既有格式的接收编号；无有效回执仍保留草稿，不声称持久化成功。
3. **会员异常误导**：法规导出遇到接口错误会走会员购买提示。现在单独提示“权益暂未确认/重试”，不要求重购，免费预览与本地内容保留。授权仍用原有服务端能力。
4. **禁用存储阻断免费工具**：培训启动时写localStorage及统计函数可抛错。加入只在当前页的退化与统计存储容错，不新增云存储或采集字段。
5. **承诺不一致**：法规入口原称“免费在线识别”而未充分前置6条限制；目录数量原静态文案535与实际536不一致。已修正，并由轻量共用说明组件保持核心工具口径一致。
6. **SEO缺口**：JSA/培训页面缺canonical；核心页缺分享摘要；JSA未入sitemap。已补齐，法规摘要同时说明会员边界。
7. **旧目录路径落到首页**：10月6日公开GET确认 /tools/、/articles/ 都返回首页正文和首页canonical；/tools 返回404。已在根首页加入固定同站白名单兼容跳转；未修改未知路由。文章目录canonical、结构化URL和sitemap指向显式index.html。
8. **维护文档过时**：README仍写GitHub Pages自动部署。已更正为源码审阅、授权OSS发布、独立Worker。
9. **JSA生成结果撑宽手机页面**：补充有数据后的回归发现390像素整页横向溢出；限制步骤表与预览的滚动容器，保留全部列与键盘访问，不隐藏风险信息。

旧目录修复是JavaScript兼容方案，不是服务器301。关闭JS的客户端/不执行JS的爬虫仍需要OSS托管层的授权重定向配置；本轮未实施该配置。没有批量删除旧URL或改动文章正文路径，也未把搜索引擎缓存当作程序故障。
