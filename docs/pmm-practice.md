# PMM 渐进式激励管理

版本 PMM-2026.09-v1；2026-09-19。

## 公开范围

入口为 `tools/pmm-coach.html`，放入首页 03 外企管理实践、专业工具导航、专业资源搜索和 sitemap。原文件未纳入 Git 或公开对象。

页面提供方法说明、两条对话路径、事实及当事人视角、工作情境、多个待核实解释、行动与复核安排、预览、Excel 导出和打印。下载区提供从空白重新制作的通用 Excel 表与 Word 指南。

## 脱敏与专业修订

没有复制原企业名称或标识、内部文号、人员元数据、原流程图、隐藏列和原文件包。使用通用岗位代号，无真实案例。将示范行为翻译修正为正向认可；将“利益动机即恶意”“额外培训无效”的绝对判断改为基于情境和证据的人工核实。来源及行业适用边界在网页和指南中列明。

## 隐私与边界

- 页面 `data-site-shell-features="local"`，CSP `connect-src 'none'`；不加载共享分析、认证或反馈脚本。
- 仅当前页面内存；没有 localStorage、sessionStorage、上传、自动保存或真实用户数据。
- DOM 使用 textContent；Excel 输入按文本写入，公式前缀转义。编辑内容会使原预览失效。
- 不计算行为得分、不自动定性、不推荐纪律处分、不批准作业。状态由使用者填写，证据须人工核实。
- 浏览器关闭前提示保存；下载文件的访问、脱敏、留存由使用者管理。

## 验收与后续

运行 `node --test tests/*.test.mjs` 和 `node tests/pmm-browser.mjs`（本地静态站默认 8773）。浏览器脚本支持 PMM_BASE_URL / PMM_QA_DIR 与本地 Playwright 路径覆盖。

已验收两种路径、三种屏幕宽度、输入修改失效、文本注入防护、Excel 下载、清空、无第三方请求及无持久化；技术结果不是现场专业批准。真实使用反馈由产品负责人自愿招募、脱敏确认。
