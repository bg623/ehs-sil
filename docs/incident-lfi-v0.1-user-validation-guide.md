# LFI产品验证版 V0.1 用户验证指南

版本：V0.1

状态：仅限3个预置纯虚构案例

安全边界：不输入、记录或上传真实企业、人员、事故、健康或附件数据

## 验证目标

验证个人EHS从业者能否在10分钟内理解并完成“快速报告—调查—整改验证—LFI推广—关闭”的闭环，以及展示级Safety Alert是否具有实际沟通价值。

## 主持流程

1. 请参与者从3个纯虚构案例中任选一个，不介绍页面操作方法；
2. 观察其能否依照进度完成12步，并记录发生困惑的步骤编号；
3. 请参与者尝试提前关闭，确认其是否理解三个强制关闭条件；
4. 完成后请其查看、下载或打印Safety Alert，并用自己的话复述关键教训；
5. 请其完成页面底部3项固定选择；选择只保留在当前浏览器会话，可由参与者当场展示；
6. 点击“一键重置演示”，确认会话状态清空后再交给下一位参与者。

## 最小观察项

- 是否在10分钟内完成；
- 首个发生困惑或退出的步骤；
- 是否正确说出调查批准、整改验证、LFI发布三个关闭条件；
- 是否能理解Safety Alert的关键教训、屏障缺口和行动验证；
- 固定选择结果：理解度、最有价值环节、实际试用意向；
- 是否主动提出愿意在虚构或脱敏场景中再次使用。

## 数据口径

页面不会上传或汇总验证结果。产品负责人如需形成周Review，应只记录用户分组和上述固定观察项，不记录姓名、企业、事故正文或联系方式。自动测试、内部演示和页面访问不得计入真实用户完成、工作采用、复访或付费意愿。

## 阶段决策

完成真实用户Review后，只选择一个主要问题进入下一轮改进。未完成Review前，不启动2A-Pilot、生产登录、真实事故填报、附件上传或生产Cloudflare数据资源。
