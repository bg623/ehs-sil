# EHS-SIL 色彩系统

版本：1.0

## 设计方法

采用 Realtime Colors 的五角色逻辑，让颜色表达界面层级，而不是在页面中随机使用相近色：

| 角色 | 色值 | 用途 |
|---|---|---|
| text | `#263238` | 正文和高优先级文字 |
| background | `#F7F4EE` | 页面背景 |
| primary | `#123B4A` | 主要按钮、标题和关键区块 |
| secondary | `#DCE9E7` | 次级按钮、标签和信息卡片 |
| accent | `#96630B` | 少量强调、链接和高价值提示 |

深色背景上的金色文字使用 `#F0C879`，避免把适用于浅色背景的强调色直接放在深色区块上。

## 使用约束

- 主色用于主要行动和结构层级；
- 次色用于弱操作、选中状态和辅助信息；
- 强调色不用于大面积背景；
- 成功、警告、危险等状态色独立于品牌色；
- 不因页面不同重新定义同名色彩角色。

## 对比度基线

| 组合 | 对比度 |
|---|---:|
| 正文 / 背景 | 11.99:1 |
| 主色 / 背景 | 10.93:1 |
| 白色 / 主色 | 12.00:1 |
| 强调色 / 背景 | 4.68:1 |
| 白色 / 强调色 | 5.14:1 |
| 主色 / 次色 | 9.63:1 |

自动化测试位于 `tests/color-system.test.mjs`。
