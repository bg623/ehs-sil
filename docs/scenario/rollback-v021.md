# V0.2.1 甲醇场景融合回退

本版只发布新的 `dist/scenario/v0.2.1/` 不可变目录，以及引用该目录的 `tools/scenario-workbench.html`。首页、资料目录、其他在线工具、DNS、VIP API及桶权限不在本次变更范围。

## 发布前

1. 保存线上 `tools/scenario-workbench.html` 的真实GET字节、SHA256、Content-Type、Cache-Control、ETag、Last-Modified。不能用Git文件替代真实生产备份。
2. 对共享前置文件做公开GET哈希核对；若线上出现并行修改，不覆盖这些前置文件。
3. 认证核验杭州 `ehs-sil` 桶，确认本次新目录不存在。新目录存在时先核对其完整内容，不覆盖已发布的不可变版本。
4. 对照发布清单，只上传新运行目录，设置清单中的UTF-8类型和immutable缓存并逐项验证。通过后再更新工具HTML，HTML使用no-cache。

## 触发与操作

若设备、液流、火焰缺失，出现串场/明显穿透、旧草稿或A快照损坏、PNG空白/失败、加载错误，先停止继续上传。恢复发布前真实工具HTML及原Content-Type/Cache-Control；不修改原文件内容、不删除用户草稿，不清空浏览器存储。验证恢复后的HTML哈希与备份一致，并确认重新引用 `v0.2.0`。

已发布的旧 `v0.1.0`、`v0.1.1`、`v0.2.0` 目录全保留。新目录先保留用于诊断；不通过不可回收删除来“回滚”，不覆盖新旧不可变目录。若用户已在本版修改草稿，仍保留其当前JSON及原始旧版备份，禁止静默丢字段。

## 验证与记录

回退后核对公开HTML及其引用、五类原场景、2D降级、草稿/A、高清PNG；记录真实结果。原Last-Modified时间无法保证原样恢复，不能把这个字段伪装成未发布过。GitHub源回退与OSS恢复分别记录，不把源提交变更当作生产恢复。

数学模型、数据审核和工程能力均不回退或提升：仍是教学演示，数值门控关闭。本次APP版本变化不授权工程计算。
