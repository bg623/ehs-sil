# V0.1.1 发布与回滚

本轮为教学增强，生产授权有效，但基线审查时 OSS 安全发布连接不可用。当前公网工具对象返回 404 与首页兜底，不是工作台；不能把该响应当作旧工具备份或已上线证明。生产对象映射与逐文件哈希见 production-readiness-v011.md。

候选清单相对真实生产 main（3be8660）生成，包含首次接入所需的首页、风险页、专题、说明脚本、索引与站点地图实际差异，以及新工具 HTML 和 v0.1.1 完整运行资源。不仅比较未发布 V0.1.0→V0.1.1，以免漏入口。

发布前：确认实际 bucket `ehs-sil` 与前缀，重新 GET/HEAD 六类接入对象与共享前置资源。记录真实旧字节、SHA256、Content-Type、Cache-Control、ETag、Last-Modified。只上传 manifest 文件，不整桶同步，不读取历史明文密钥。

顺序：新版本模块、Worker、数据、CSS、许可证 → 核验哈希/MIME → 工具HTML → 冷缓存体验默认甲醇、局部替换、迁移、导出及2D → 实际入口变更 → sitemap → 公开全流程验收。保持根站OSS与独立会员接口，不修改DNS、桶权限或收费。

若发生串场、草稿丢失、门控提升、无3D/2D可用路径、MIME不对或敏感网络请求：先恢复入口对象，避免用户继续进入。新工具没有真实旧对象时，将其改为清晰临时说明页；不能把404首页伪装成旧工作台。已有旧对象时仅恢复其真实备份及元数据。

完整保留 dist/scenario/v0.1.0 与 v0.1.1，不删除已打开页面所需资源。旧V0.1.0候选与原manifest仍在旧工作副本及PR历史；若明确选择回退为旧教学工具，先上传其完整依赖再切HTML，不能只改入口却缺旧资源。

数据：v1键 `ehs-sil-scenario-project-v1` 保留原字节；新数据写v2和本模块上一草稿键，不动其他工具。迁移/保存失败保留内存与旧键，提供JSON。主动清除v2写本模块清除标记，防v1意外复活；v1仍可供旧程序回滚读取。V0.1.1之后只写v2的新增修改，旧版不会自动读取，应先下载新版JSON并保留当前恢复工具；不得声称v1同步了全部新字段。

本轮不得将数学核查、软件GPU结果或CI通过替代物理验证、3名真实新手体验、真实手机或生产验收。实际生产上传与公开检查状态单独记录。
