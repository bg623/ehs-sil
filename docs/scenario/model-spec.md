# 模型与技术状态 · V0.1

公开模型为定性机制教学（pool-fire-teaching 0.1.0），不输出工程数值。工况、物质、库存、面积与措施用于资料记录，不能据画面估计距离。项目坐标东 x、北 y、上 z，m；Three.js 映射 (x,z,-y)。动画仅是 0–1 进度映射到六阶段，非事故时间。

机制卡为基于部署指南 §3.5 的编辑说明。进一步学习来源：NOAA / EPA, ALOHA Technical Documentation, November 2013，官方资源入口 https://response.restoration.noaa.gov/oil-and-chemical-spills/chemical-spills/resources/aloha-technical-resources.html 。本轮读取了资源索引及其文档用途说明，未把未逐页核查的参数或公式宣称为 ALOHA 数值实现；不复制其图示或完整求解器。Six mechanisms 的条件检查是人工确认前提清单，不是概率模型或“不发生”判定。

## 数值草案的明确边界

候选范围：室外、单一可燃液体、已知有限释放质量、经确认的固定液池、充分发展稳态阶段。排除混合物、闪蒸、动态铺展、持续供料、风、复杂地形、毒性、爆炸与近场。还没有经验证的池火辐射模型，不能选择一个 R/D 作为无出处的有效距离。

已实现但不对项目开放的数学组件：

- 理想各向同性点源：q = Qrad × τ / (4πR²) / 1000。Qrad W，R m，τ 无量纲 [0,1]，输出 kW/m²；不是生产池火模型。
- 固定质量收支：消耗速率 = A × m''；持续时间 = M / 速率；消耗质量截断于 M。M kg，A m²，m'' kg/(m²·s)，t s。
- 期望值来自指南 §6.5 的独立合成核查；fixtures 不从被测函数生成。相对/绝对浮点容差为 1e-14（理想点源组件）。0 质量可以核查 0 时长；0 面积 / 非有限值拒绝。

暂不提供真实物质燃烧通量、燃烧热、辐射分数、大气传递率、火焰几何关联式、阈值和近场边界。没有火焰几何、稳态池火场解、求根域或目标距离求解器可以对项目使用；近场、超出域等路径由门控统一阻断，不返回 0。未来逐项获得真实方法与参考算例后另发模型版本。

## 数值开放所缺证据

1. 具体池火方法、可定位公式、合法引用范围和适用边界；
2. 每个物质所需字段及其温压、纯度、来源与审核；
3. 对应该方法的独立参考算例、物理验证及误差准则；
4. 对本实现、数据、近场与阈值口径的真实技术评审。

模型注册表的 verified 只指教学结果状态和数学组件代码检查；validationEvidence 为空、technicalReview=null。生产 screeningEnabled=false，approvedChemicalIds=[]。教学液体 A 是合成代称，没有 CAS，也没有工程物性。导入的审核声明不能改变随发布包携带的门控。

## 状态与结果约定

版本分别管理 schemaVersion、appVersion、modelVersion、dataVersion、inputRevision 以及 calculationId/inputHash。SHA-256 对按键排序的输入、措施、假设与来源生成，不含视角、进度、日期或标题。它用于复现关联，不是签章。

任何关键输入改变：修订号增加，原结果 stale；Worker 必须同时匹配任务 ID 与修订号。导入丢弃可信结果；导出只使用当前结果，过期时输出当前输入与待重算。所有未评估物理量值为 null、附原因码。

A 是独立完整输入与模型/资料版本的冻结副本；B 是当前记录，差异使用 SI 单位，不生成风险降低百分比。措施全部 recorded_only；SIS 和切断时间不能自动改变工程结果。固定面积下减少有限质量的数学核查只改变时长，不自动缩小稳态辐射。
