# V0.2.0 首次使用者视觉试用

状态：not_run。此页是招募和记录模板，没有预填评分，没有把开发者看图当作用户认可。

对象：至少3名未参与开发的使用者。分别记录操作设备、浏览器和是否首次使用；不要求提供企业事故资料。使用虚构预设，不输入真实装置数据。

## 任务

1. 不读长说明，打开甲醇示例并播放，旋转至侧面/背面，暂停和拖动阶段。
2. 切换正庚烷与甲醇自然/辅助模式，描述看见的区别，确认“难看见不等于无热危险”。
3. 分别载入喷射火、闪火和VCE，指出释放口、点火位置、传播前沿和障碍环境。确认切换完整示例与“只换事故”不是同一动作。
4. 载入受限空间爆燃，切剖面与外观，说明内部燃烧和开口外焰关系。
5. 选择近景导出1920×1080 PNG与元数据；检查图片对应当前物料、事故、镜头、阶段和辅助模式。
6. 修改一项条件、冻结A、备份JSON；复述哪些画面或输出不能用于工程判断。
