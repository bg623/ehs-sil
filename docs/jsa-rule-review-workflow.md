# 工作安全分析（JSA）专业规则审核工作流

## 审核入口

可视化审核页：`dashboard/jsa-rule-review.html`

页面从`data/jsa-rules.json`读取候选规则，并从`data/jsa-source-catalog.json`读取已核实来源，但不会直接修改规则库或发布生产规则。

## 产品负责人操作

1. 填写审核人和审核日期；
2. 逐条检查适用场景、触发条件、风险提示、原因和建议行动；
3. 为每条规则选择：
   - `approved`：专业内容认可，可进入内部测试；
   - `needs_revision`：需要修改，必须填写修改意见；
   - `rejected`：不采用，必须填写拒绝原因；
   - `pending`：暂不决定；
4. 查看每项来源的中英文名称、适用范围说明和官方链接；
5. 确认来源是否适用于该规则和目标使用场景，必要时修改“审核采用的专业来源或参考标准”；
6. 点击“下载审核结果”，将结构化审核文件（JavaScript Object Notation，JSON）交给Codex处理。

来源目录已核对官方发布页面，但“已核实”不等于自动认定法规适用或合规。GB 30871-2022仅适用于其规定的危险化学品、化工和医药企业范围；其他行业需结合本行业要求确认。高处作业来源使用现行GB 3608-2025，不再使用已废止的GB/T 3608-2008。

审核草稿仅保存在当前浏览器的本地存储（localStorage）中，不包含网站管理凭据、激活码或工作安全分析（JSA）作业内容。

## Codex后续操作

收到审核结果后，Codex负责：

1. 校验规则库版本、规则编号和审核字段；
2. 根据审核意见修改规则；
3. 将产品负责人批准结果写入结构化规则库；
4. 关联产品负责人提供的脱敏黄金案例；
5. 执行规则引擎、治理门槛和黄金案例回归测试；
6. 更新发布记录并提交独立commit；
7. 报告测试结果和仍未满足的上线条件。

## 状态边界

审核页中的“批准”只表示产品负责人认可专业内容，可以进入内部测试，不表示：

- 规则已经上线；
- 作业安全；
- 符合法规；
- 风险已经可接受；
- JSA可以批准。

生产环境仍只允许加载同时满足专业审核、黄金案例覆盖和回归测试要求的规则。
