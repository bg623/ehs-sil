# 企业适用法规智能识别 V1.6

日期：2026-09-11。基线提交：8407989。范围仅限本工具，不修改首页、会员权益、DNS、Worker 或 D1。

## 针对反馈的交付

- 新增官方核验增强包：安全 20 项、环境 16 项；与原库去重后，当前启用 106 项，其中 41 项来源已核验。停用 8 项被生态环境法典替代的旧环境法律，不以新旧并列增加条数。
- 116 组结构化条款卡。按画像筛选条款、解释范围、生成义务摘要、建议动作和证据要求，展示精确官方来源。
- 41 条旧规则范围纠错：避免普通工贸命中药品生产、医用放射、爆破、化工检修等专门要求。
- 法规效力、来源核验、画像适用性、现场符合性四个概念分开。标准仅完成元数据核验时不显示“全文已核对”。
- 基础画像加按需追问；未填写、明确否、明确是分开处理。特殊作业明细仍可选；具体作业推导总项，不要求用户全部展开。
- 增加条款快捷卡片与独立展开区，避免必须横向滚动台账才能看到条款。
- 四表 Excel 同步完整画像、条件依据、条款摘要、建议动作、证据索引和版本重评提示。实际证据不由建议文本冒充。
- 旧画像的“废水、废气或噪声”不再转换为三者全有；历史评价保留，新版规则不自动沿用旧“符合”判断。
- 新增 profile_refined、evidence_recorded 行为事件，仅记录事件和示例/用户模式，不采集企业名称、画像答案、证据或人员信息。

## 验证与边界

执行 `node scripts/build-compliance-v16-release.mjs`、`node scripts/validate-compliance-v16.mjs`、`node --test tests/compliance-*.test.mjs`。合规回归 22 项通过，包含 Excel buffer 导出回读；这是软件回归，不是 22 位用户测试或专业专家批准。

全站单元测试尝试执行 98 项：94 项通过，4 项其他模块测试因系统临时目录写权限（EPERM）未完成，不把环境阻断记为通过。静态链接检查覆盖 68 个 HTML、581 个引用，无断链；敏感信息扫描未发现生产凭据。

浏览器实际验证：桌面与 390px 手机布局下的示例识别、独立条款卡；填写证据索引后登记进度即时更新为 1/6；未激活账号点击完整 Excel 导出仍显示原会员提示。示例操作不是客户记录，不代表企业已履行条款。会员认证延迟返回不会在权益未改变时关闭已打开的条款卡。

法规原文来源和条款处理见 `compliance-environment-sources-v16.md`、`compliance-safety-sources-v16.md`。本轮没有新访谈、真实企业验证样本、购买或续费数据，不推断转化提升。

尚未穷尽地方排放标准、所有行业专门标准、许可证专属条件和现场事实；未匹配不能解释为没有法律义务。剩余候选来源不自动升为已核验。系统不自动计算重大危险源阈值、排放限值、监测/体检具体项目，不在缺少参数时编造结论。

旧固定 Excel 下载标为“旧版格式参考”，不作为当前法规依据；当前画像使用专业导出获取 V1.6 内容。

## 发布及回退

使用独立的 `dist/compliance-v1.6.0.js`、CSS 和三个增强数据文件。先上传并验证这些新路径，最后替换工具 HTML。现有 `js/compliance-*.js` 生产对象保持不动，缓存旧 HTML 的用户不会读到不兼容的新脚本。

只同步 6 个公开对象到既有阿里云杭州 OSS；记录原 HTML 备份、每个对象 SHA-256 和 HTTP 冒烟结果。必要时恢复原 HTML 即可回退，不删除新数据文件，不接触用户本地记录。

真实使用验证待产品负责人选择覆盖机械制造、化工、一般仓储等场景的脱敏样本；优先比较漏项、错误适用、关键追问数量及要求是否可直接落地。
