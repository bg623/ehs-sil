# 合规识别法规数据治理

## 发布边界

合规识别工具只提供初步完整性识别，不构成法律意见，不自动判断企业已合规。`data/regulations.json` 是正式受控库；`data/regulation-updates.json` 仅保存候选，任何候选都必须经产品负责人核验后才能进入正式库。

## 核验状态

- `已核验`：名称、文号、日期和官方来源已逐项核对，并记录核验日期。
- `待复核`：保留用于速查或初步标签匹配，但界面明确提示人工确认。

自动检查只能产生候选及来源状态，不得直接覆盖正式库。地方要求必须同时满足地区和业务触发条件；没有受控数据的省市应提示用户结合当地主管部门最新要求复核。

## 人工审核清单

1. 核对官方原文、现行状态、替代关系与实施日期；
2. 审核行业、企业类型、风险和活动标签；
3. 审核适用条款摘要与推荐责任部门；
4. 用山东淄博和江苏机械制造画像进行回归；
5. 记录审核人、日期和发布说明。
