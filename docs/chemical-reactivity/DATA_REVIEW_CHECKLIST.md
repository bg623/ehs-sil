# 化学品反应性数据审查清单

每次新增或更新生产快照时逐项签署。本清单未完成，不得把来源模式切换为 `approved_snapshot`。

## 权利与来源

- [ ] 明确数据权利人、许可文本、允许字段和再发布范围
- [ ] CAS、同义名、NFPA 等第三方字段已有单独书面授权或已排除
- [ ] 未抓取网页 HTML，未依赖非公开接口
- [ ] 每条记录可追溯到来源 ID、记录 ID、版本和复核日期
- [ ] 来源名称不暗示 NOAA/EPA/AIChE/CCPS 背书

## 数据包治理

- [ ] 数据版本、生成时间、复核人、校验和及变更日志完整
- [ ] 所有记录 `reviewStatus=APPROVED`
- [ ] `TEST_ONLY`、撤回、过期和校验失败记录为零
- [ ] 生产构建脚本与数据闸门通过
- [ ] 快照失效时已验证自动回退 `official_assist`

## 专业质量

- [ ] 至少 30 组真实化学品与同版本 CAMEO/CRW 人工对照
- [ ] 覆盖多反应组、产热、产气、升压、毒性/易燃气体、强烈反应、水反应和未知
- [ ] 气体名称全部来自获准数据字段，无模板或模型猜测
- [ ] 直接证据与组对冲突能触发 `CONFLICT_REVIEW`
- [ ] 对角线 SR/X/? 与同版本官方工具逐项核对
- [ ] CRW 参考情景、来源代码和外推警告已由专业人员复核
- [ ] 人工修订保留原预测并完成第二人复核与版本失效测试
- [ ] EHS/化工专业人员签名、日期和适用边界已记录
